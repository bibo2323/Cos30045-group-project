READING THE DATA

Built from the KNIME outputs

These charts use the five supplied CSV files in the Knime Data folder. These numbers show hospital visits, not the number of different people or each person’s chance of being hospitalised. Percentages are calculated separately for each race, state, group, or year to make fair comparisons.
